# Validation-v2 frozen treatment source

These two files are the exact treatment source used for the completed
validation-v2 matrix. They were recovered from the remote experiment workspace
before the development-only `context_dualcap_G4S5` implementation replaced the
working copies.

The hashes in `SHA256SUMS` match the validation-v2 treatment freeze manifest.
The files are retained only for byte-exact reproduction of validation-v2; new
development and validation-v3 work must use the current sources under `src/`
and `scripts/`.
